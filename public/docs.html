Transcription API

Convert audio and video files to structured text. The API is asynchronous — you submit a file, receive a job ID, and poll until the result is ready.

Base URL http://localhost:8080
ℹ No authentication required. The API is intended for local or internal network use.

Workflow

1
Upload a file
POST to /api/transcribe.php with your audio or video file and the desired language. Returns a job_id immediately.
2
Poll for status
GET /api/transcribe.php?job_id=N every 2–3 seconds. The status field moves from processing → done (or failed).
3
Read the result
When status is done, the response contains the full text, a segments array with timestamps, and download URLs for TXT, JSON, and PDF.

Minimal example

# 1. Upload
curl -X POST http://localhost:8080/api/transcribe.php \
  -F "file=@meeting.mp3" \
  -F "language=ru"

# → {"job_id": 12, "status": "processing", "poll_url": "..."}

# 2. Poll
curl "http://localhost:8080/api/transcribe.php?job_id=12"

# 3. Download TXT when done
curl "http://localhost:8080/api/download.php?job_id=12&type=txt" -o result.txt

Create a transcription job

POST /api/transcribe.php multipart/form-data

Request fields

FieldTypeRequiredDescription
file file required Audio or video file. See supported formats.
language string optional Transcription language. One of kz, ru, auto. Defaults to auto.

Response 202

{
  "job_id":   12,
  "status":   "processing",
  "poll_url": "http://localhost:8080/api/transcribe.php?job_id=12"
}

Get job status & result

GET /api/transcribe.php?job_id={id}

Query parameters

ParamTypeDescription
job_id integer ID returned by the POST endpoint.

Response while processing processing

{
  "job_id":  12,
  "status":  "processing",
  "message": "🧠 Часть 2/4: транскрибируем..."
}

Response when done done

{
  "job_id":  12,
  "status":  "done",
  "text":    "[00:00:00 - 00:00:22] Speaker 1: Текст транскрипции...",
  "segments": [
    {
      "start":   "00:00:00.000",
      "end":     "00:00:22.400",
      "speaker": "Speaker 1",
      "text":    "Текст транскрипции первого сегмента"
    }
  ],
  "downloads": {
    "txt":  "http://localhost:8080/api/download.php?job_id=12&type=txt",
    "json": "http://localhost:8080/api/download.php?job_id=12&type=json",
    "pdf":  "http://localhost:8080/api/download.php?job_id=12&type=pdf"
  }
}
⚠ The pdf key is only present when PDF generation succeeded. Always check before using.

Download result file

GET /api/download.php?job_id={id}&type={type}

Query parameters

ParamTypeDescription
job_id integer Job ID.
type string One of txt, json, pdf.

Returns the file with the appropriate Content-Type header and a Content-Disposition: attachment prompt.

curl "http://localhost:8080/api/download.php?job_id=12&type=pdf" \
  -o transcript.pdf

Languages

ValueLanguageEngine
kz Kazakh Mangisoz STT
ru Russian Mangisoz STT
auto Auto-detect Google Gemini

For kz and ru, long files are automatically split into 20-second chunks to prevent word loss at Mangisoz's internal segment boundaries.

File formats

TypeExtensions
Audio mp3  wav  m4a  aac  ogg  oga  opus
Video mp4  mov

Video files are automatically converted to audio before transcription. The extracted audio is also returned as a separate download.

Error codes

HTTPConditionBody
400 Missing or invalid field {"error": "No file uploaded"}
404 Job ID not found {"error": "Job not found"}
405 Wrong HTTP method {"error": "Method not allowed"}
415 Unsupported file type {"error": "Unsupported file type: xyz"}
500 Transcription failed {"error": "...", "status": "failed"}

All error responses are JSON with a top-level error string describing what went wrong.
